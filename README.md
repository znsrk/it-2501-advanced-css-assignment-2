Assignment parts

Part 1. Flexbox
Task 0. Navigation Bar
The header contains a logo and navigation links aligned horizontally with Flexbox. The items are vertically centered and spaced evenly.

Task 1. Card Row
The page contains three cards. Each card has an image, title, text, and button. Flexbox creates the row, keeps the card content equal in height, adds consistent gaps, and provides a hover lift effect.

Part 2. Grid System
Task 2. Page Layout with Grid Areas
The page layout uses CSS Grid with named areas for the header, sidebar, main content, and footer.

Task 3. Image Gallery
The gallery contains nine images arranged in equal-width Grid columns and rows. Each image displays a caption overlay when hovered.

Part 3. Combining Flexbox and Grid
Task 4. Portfolio Page
The portfolio uses Grid for the projects area and information sidebar. Each project card uses Flexbox to arrange its title, description, and button. The footer spans the page width.

Work summary

The project is implemented with semantic HTML and plain CSS. Flexbox is used for navigation, cards, and project content. CSS Grid is used for page areas, the image gallery, and the portfolio layout. A responsive media query adapts the layout for smaller screens.
